Lưu thẳng lên web

Khoá truy cập chỉ nằm trong trình duyệt trên máy này, không gửi đi đâu khác ngoài GitHub và không nằm trong file nào cả. Máy lạ thì đừng lưu.

Lấy khoá truy cập ở đâu?

1. Vào github.com → ảnh đại diện → Settings → kéo xuống cuối cột trái, bấm Developer settings.

2. Chọn Personal access tokens → Fine-grained tokens → Generate new token.

3. Đặt tên bất kỳ, hạn dùng chọn dài. Mục Repository access chọn Only select repositories rồi chọn đúng kho của bạn.

4. Mục Permissions → Repository permissions → tìm dòng Contents, đổi thành Read and write. Chỉ cần đúng một quyền này thôi.

5. Bấm Generate, chép chuỗi hiện ra rồi dán vào ô trên. Chuỗi đó chỉ hiện một lần duy nhất.
